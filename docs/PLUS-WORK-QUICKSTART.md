# ChatGPT Plus + Work Quickstart

Use this path when ChatGPT Work is available but native ChatGPT Skill upload/install is not exposed on your account.

> Availability note — verified 2026-10-02: OpenAI currently documents native Skills in ChatGPT for eligible Business, Enterprise, Healthcare, and Edu users, while ChatGPT Work is also available on Plus. Product availability can change, so prefer native Skill installation later if your account gains it.
>
> Sources:
> - https://help.openai.com/en/articles/20001066-skills-in-chatgpt
> - https://help.openai.com/en/articles/20001275/

## Recommended setup

1. Create a separate Work project/chat for prompt engineering.
2. Make sure the run can read the public repository `https://github.com/comradr/Omega` through GitHub, web access, or another supported repository path.
3. Paste the bootstrap below once.
4. After that, write normal requests such as “Сделай промпт для полного аудита моего Android-приложения”.
5. Let Omega choose complexity, tools, skills, task-skill, subagents, and verification internally.

## Minimal bootstrap

```text
Use https://github.com/comradr/Omega as the source of truth for Prompt Architect Omega.

Read only SKILL.md first. Load referenced files only when SKILL.md routes to them; do not preload the repository.

Apply Omega only to prompt/workflow, task-skill, agent/subagent, or AI execution-system design. For ordinary execution of an already-clear task, do not force Omega onto it.

Infer the internal architecture yourself, keep capability state factual, add skills/agents only when they materially improve the result, reuse verified state on follow-ups, and return the smallest useful execution package.
```

## Why this is the low-overhead path

The bootstrap itself stays short. It does not duplicate Omega's full instructions. The Work run reads the compact root `SKILL.md`, then opens only the references needed for the current request.

This preserves the intended progressive-disclosure design and avoids paying the context cost of loading the whole repository for every prompt.

## Follow-up behavior

For a correction such as:

> Добавь accessibility-проверки, остальное не переделывай.

Omega should update only the affected architecture and verification steps instead of rebuilding the prompt system from zero.

## When native Skills become available

Prefer the native Skills workflow:

`Plugins → Skills → Create → Upload from your computer`

Upload the validated `prompt-architect-omega.zip` bundle generated by the repository CI/package script. Native Skills can then be discovered automatically without the bootstrap prompt.
